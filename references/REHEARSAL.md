# 합성 과제로 행동을 확인하십시오
실제 시험 문제를 재현하거나 자료를 옮기지 마십시오. 작은 가상 회의실 예약/장비 대여 등 독립 과제로 연습하십시오.
학습 목표는 전체 앱의 성능 경쟁이 아니라 이 스킬이 실제 협업·이해·검수 행동으로 이어지는지입니다.

필수 확인:
- 중요한 규칙 해석이 구현 후가 아니라 결정 시점에 전달되는가.
- 사소한 구현마다 사용자 승인 대기하지 않는가.
- 초기 작동 흐름이 실제 데이터와 연결되는가.
- 구현자가 사용법을 설명하지 않은 상태에서 독립 검토자가 목표를 끝내는가.
- DOM만 보았을 때 시각 검증을 주장하지 않는가.
- 사용자가 안 했던 확인을 했다고 적지 않는가.
- 실제 입력 변경과 오류·복구를 테스트하는가.
- 사용자가 핵심 선택의 이유와 미검증 한계를 자기 말로 설명하는가.
- 새 환경에 같은 스킬을 설치하고 인식하는가.

이 묶음의 자동 테스트와 browser_smoke.py는 위 행동·제품 품질을 입증하지 않습니다.
자동 테스트는 설치·게시 경계의 안전성을, 브라우저 smoke는 합성 페이지의 클릭·입력·상태 확인 가능성만 검증합니다.
